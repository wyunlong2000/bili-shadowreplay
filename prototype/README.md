# ShadowReplay 界面原型

保留蓝灰配色与圆角风格，展示导航分组、统计层级和统一的页面控件。

## 运行

直接使用浏览器打开 `index.html`，无需安装依赖或连接网络。

也可在仓库根目录启动本地预览：

```powershell
python -m http.server 8055 --bind 127.0.0.1 --directory prototype
```

访问 [本地预览](http://127.0.0.1:8055/)。

## 预览范围

- 总览：实时联动直播间在线/缓存统计、最近录播（含 AI 摘要标识）、直播中的房间快捷卡片、存储与账号状态。
- 直播间：平台筛选、主播/标题/房间号搜索、4 态检测状态（直播中 / 未直播 / 状态未知 / 等待检测）、封面房间号水印、右上角更多菜单（自动切片设置 / 打开网页 / 移除直播间）与自动录制开关。
- 录播 / 素材 / 切片 / 投稿 / 任务 / 助手 / 账号 / 设置 / 关于：补齐全部 11 个导航页面的可交互预览视图，涵盖按房间筛选录播、切片工程与自动切片候选双视图切换、AI 助手对话及任务中心浮层。
- 公共交互：侧边栏手动折叠、舒适/紧凑信息密度切换、深浅主题切换、可实际新增卡片的添加直播间弹窗与自动切片配置弹窗。

全部使用本地示例数据，不连接后端或创建真实录制任务；浏览器允许时，页面、主题、密度与侧栏折叠状态会保存在本地。

## 文件组织

- `index.html`：全页面结构与弹窗入口。
- `styles.css`：配色、组件样式与自适应布局。
- `app.js`：示例数据、状态联动与交互逻辑。
- `assets/`：应用图标、项目已有的 Lucide 图标数据及授权声明。
