## 1. 使用规则

- 本文是开发任务的唯一执行清单，任务完成后填写实现文件、验证结果和关联提交。
- 任务编号保持稳定；任务拆分或范围变化时追加编号并记录原因。
- `BLOCKED` 表示存在会改变接口、数据结构或事件语义的待确认事项；未解除前不实现依赖任务。
- 每个任务完成后更新状态：`TODO`、`IN_PROGRESS`、`BLOCKED`、`DONE`。
- 代码实现必须回链到详设章节、`REQ-*` 和 `AC-*`；验证失败保留原因和后续动作。

## 4. 停止条件

遇到以下情况时暂停依赖任务并请求确认：

- 抖音接口无法得到稳定的在播响应或字段语义与详设不符；
- 需要改变 `room_id`、`sec_uid`、`web_rid` 的数据库语义；
- 现有事件或 Webhook 消费者无法保持兼容；
- 分析窗口无法从现有缓存稳定重建；
- 邮件链接需要引入认证、签名 URL 或新的部署组件；
- 详设与实际代码生命周期冲突，且存在重复录制、重复切片或重复通知风险。
